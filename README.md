# Interactive Image Slider

A lightweight image slider built with HTML, CSS, JavaScript, and TypeScript. Users can navigate between slides using previous and next controls.

## Features
- Previous and next navigation buttons
- Multiple image slides
- Simple, lightweight front-end implementation
- CSS-based slide movement

## Built With
- HTML5
- CSS3
- JavaScript
- TypeScript source file

## Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/anishshaikh1412/slider.git
   ```
2. Open the project folder.
3. Open `index.html` in a browser.

## Project Files
- `index.html` — slider markup
- `style.css` — slider styling
- `script.js` — slide navigation logic
- `script.ts` — TypeScript source

## Notes
The slider uses image URLs from external sources, so those images require an internet connection and may change or become unavailable.
